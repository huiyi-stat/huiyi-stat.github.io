# Hui Yi — academic homepage

Static site in the al-folio layout: six pages (About, Publications, Projects, Teaching, Team, CV).
Plain HTML/CSS/JS, so GitHub Pages serves it as-is with no build step.

## Folder layout
- `index.html`, `publications.html`, `projects.html`, `teaching.html`, `team.html`, `cv.html` - the pages
- `assets/css/main.css`, `assets/js/site.js` - dark-mode/menu/Bib buttons
- `assets/img/prof_pic.jpg` - portrait photo
- `assets/img/publication_preview/` - icons for journal articles and manuscripts under review
- `assets/img/report_preview/` - icons for technical reports
- `assets/img/project_preview/` - icons for projects
- `assets/pdf/Hui_Yi_CV.pdf` - CV
