# Hui Yi — academic homepage

Static site in the al-folio layout: six pages (About, Publications, Projects, Teaching, Team, CV).
Plain HTML/CSS/JS, so GitHub Pages serves it as-is with no build step.

## Folder layout
- `index.html`, `publications.html`, `projects.html`, `teaching.html`, `team.html`, `cv.html` - the pages
- `assets/css/main.css`, `assets/js/site.js` - styling and the dark-mode/menu/Bib buttons
- `assets/img/prof_pic.jpg` - portrait photo (4:5)
- `assets/img/publication_preview/` - icons for journal articles and manuscripts under review
- `assets/img/report_preview/` - icons for technical reports (country flag colors)
- `assets/img/project_preview/` - icons for projects (target population)
- `assets/pdf/Hui_Yi_CV.pdf` - full CV download

To swap any icon for a real figure or report cover, save the new image under the same file name (about 4:3).
